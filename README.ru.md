### BetterDisplay HID Idle Dimmer

Если на Mac mini автономно работают **Codex, Roblox Studio, Blender** или другие программы, физические мониторы не всегда должны оставаться яркими. В то же время выключение дисплеев и переходы macOS в режим блокировки иногда мешают сценариям удалённой и GUI-автоматизации.

Этот проект сочетает [BetterDisplay](https://github.com/waydabber/BetterDisplay), [Hammerspoon](https://www.hammerspoon.org/) и небольшую программу на C, которая измеряет время отсутствия ввода в аппаратно-ориентированном HID-счётчике macOS.

> [!IMPORTANT]
> **Это не средство обхода блокировки macOS.** Утилита не разблокирует компьютер, не обходит пароль и не устраняет защитные окна Codex / Computer Use. **Теоретически** она может уменьшить проблемы, связанные с *выключением дисплеев при бездействии*: рабочий стол остаётся активным, а изображение мониторов просто затемняется. Реальная системная блокировка — отдельный механизм.

## Версия 2.3 — только программная яркость

**Для мониторов, подключённых одновременно к Mac и Windows.** Версия 2.3 меняет только параметр BetterDisplay `softwareBrightness`: аппаратные значения через DDC не записываются, поэтому картинка Windows не должна темнеть. **Подсветка LCD при этом физически не выключается** — остаточное свечение нормально.

**По умолчанию:** 10 минут без физического ввода → 0% программной яркости Mac; физическая активность → восстановление индивидуальной программной яркости. Перед обновлением со старой версии восстановите яркость аварийной комбинацией: при наличии старого файла снимка установщик остановится.

## Возможности

- Через заданное время бездействия (**10 минут** по умолчанию) затемняет **два монитора**.
- Работает через **Software Brightness** BetterDisplay: затемняет изображение macOS, не изменяя аппаратную яркость мониторов.
- Отдельно запоминает и восстанавливает яркость основного и дополнительного дисплеев.
- Старается отличать физическое движение мыши и клавиатуры от синтетических событий приложений, включая Codex. **Это вероятностное различие, не гарантия.**
- Может обнаруживать стандартное подключение Apple Screen Sharing / VNC по TCP 5900.
- Имеет контрольный таймер, обработчики пробуждения, журнал диагностики, резервное сохранение яркости.
- Не записывает нажатые клавиши, координаты курсора, скриншоты или пароли.
- Аварийно восстанавливает яркость по **Control + Option + Command + R** с приостановкой затемнения на 30 минут.

## Требования

- Mac под управлением macOS с **двумя активными мониторами**.
- BetterDisplay в `/Applications` с включёнными CLI и **программными настройками изображения** на обоих мониторах (доступность функций может зависеть от лицензии).
- Hammerspoon с разрешением **Универсальный доступ / Accessibility**.
- Apple Command Line Tools (для компиляции маленького помощника на C).
- Обычный открытый пользовательский графический сеанс macOS.

Скрипт рассчитан на схему **один основной + один дополнительный монитор**. Более двух мониторов этой версией не поддерживаются.

## Установка

1. Установите BetterDisplay и Hammerspoon. Предоставьте Hammerspoon доступ в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
2. В BetterDisplay включите **Enable software-based video adjustments** на каждом мониторе и разрешите использование CLI.
3. Если средства разработчика ещё не установлены, выполните:

   ```bash
   xcode-select --install
   ```

4. Скачайте исходный код с GitHub и запустите установщик:

   ```bash
   git clone https://github.com/bighaired/betterdisplay-hid-idle-dimmer.git
   cd betterdisplay-hid-idle-dimmer
   bash install.sh
   ```

5. В меню Hammerspoon выберите **Reload Config**. Установщик скомпилирует HID-утилиту, предварительно проверит мониторы и сохранит резервные копии существующих файлов Hammerspoon. `sudo` не нужен.

### Первый запуск и обновление

Утилита **сразу настроена на 600 секунд и 0% программной яркости**, поэтому перед длительным бездействием проверьте восстановление обоих дисплеев физическим движением мыши. Аварийная комбинация: **Control + Option + Command + R** (возврат яркости и пауза на 30 минут).

При обновлении с Combined Brightness сначала восстановите яркость через старую аварийную комбинацию. Пока существует `~/.hammerspoon/betterdisplay_idle_dim.snapshot`, установщик намеренно не заменит старый скрипт. Установка создаёт резервные копии с отметкой времени.

Параметры в `~/.hammerspoon/betterdisplay_idle_dim.lua`:

```lua
local IDLE_SECONDS = 600  -- 10 минут
local DIM_LEVEL = 0.0     -- 0% программной яркости macOS
```

Проверьте работу Codex Computer Use и удалённого Screen Sharing отдельно: синтетические события иногда распознаются как аппаратные.

**Важно:** 0% программной яркости не выключает подсветку LCD, а удалённый захват может показывать затемнённое изображение.

## Проверка и журнал

Обычный Терминал:

```bash
BD=/Applications/BetterDisplay.app/Contents/MacOS/BetterDisplay
"$BD" get -displayWithMainStatus -softwareBrightness
"$BD" get -displayWithNonMainStatus -softwareBrightness
~/.hammerspoon/physical_idle_query --both
tail -n 40 ~/.hammerspoon/betterdisplay_idle_dim.log
```

В Hammerspoon Console:

```lua
print(BDIdleDimStatus())
```

Если `HID_SECONDS` уменьшается практически до нуля от движений **вашей** мыши, аппаратная активность распознаётся. Но некоторые инструменты автоматизации также могут влиять на этот счётчик.

## Как отключить или полностью удалить

> [!CAUTION]
> **Если экраны стали чёрными и не восстанавливаются:** нажмите **Control + Option + Command + R**. Утилита восстановит сохранённую яркость и приостановит затемнение на **30 минут**.

### Временная пауза на 30 минут

Нажмите `Ctrl + Option + Cmd + R`. Ничего удалять не требуется.

### Полностью отключить автоматическое затемнение, не удаляя файлы

В папке проекта запустите:

```bash
bash disable.sh
```

Затем обязательно нажмите **Hammerspoon → Reload Config**. При перезагрузке модуля сохранённая яркость восстанавливается, а затемнение не запускается.

Чтобы снова включить:

```bash
bash enable.sh
```

И опять **Reload Config**.

### Полностью удалить утилиту

Если экраны затемнены, сначала воспользуйтесь аварийной комбинацией. Затем:

```bash
bash uninstall.sh
```

**После команды обязательно Hammerspoon → Reload Config** (либо закрыть и снова открыть Hammerspoon). Иначе уже запущенные таймеры могут остаться в памяти до перезагрузки конфигурации.

Установщик удалит только файлы этой утилиты (`betterdisplay_idle_dim.lua`, `physical_idle_query`), её строку загрузки из `~/.hammerspoon/init.lua` и служебный маркер. **BetterDisplay и Hammerspoon останутся установленными.** Резервные копии и журнал сохраняются для диагностики — их можно удалить вручную позднее.

Если ранее вы вручную изменяли настройки сна или блокировки macOS, возвращайте их через **Системные настройки**: эта утилита их не меняет.

### Восстановить яркость без Hammerspoon

```bash
bash restore-brightness.sh
```

При наличии файла с сохранёнными значениями будут использованы эти значения. Если снимка нет, скрипт задаёт **100% программной яркости** обоим мониторам; старые снимки комбинированного режима восстанавливаются по сохранённому типу. Запускайте команду только при необходимости восстановления.

## Может ли это помочь с проблемой блокировки Mac + Codex?

**В теории — в некоторых сценариях да.** Идея заключается в том, чтобы macOS продолжала поддерживать графический сеанс и не отправляла дисплеи в обычный сон из-за отсутствия ввода, а пользователь при этом видел почти чёрные мониторы. Это может быть полезно для длительной работы Codex с Roblox Studio, Blender и другими GUI-приложениями.

Но нужно чётко различать:

| Событие | Утилита может помочь? |
|---|---|
| Экран выключается из-за отсутствия активности | **Да, в поддерживаемой конфигурации**: предотвращает idle display sleep и затемняет изображение |
| Работа Codex вызывает лишнее включение мониторов | **Возможно**: фильтрация синтетического ввода не гарантируется |
| Настоящая блокировка пользовательского сеанса macOS | **Нет**, пароль и политики macOS остаются в силе |
| Окно «ChatGPT is Using Your Mac» / ограничения Computer Use | **Не гарантируется**, это отдельный механизм безопасности |
| Удалённое подключение Screen Sharing | **Частично**: обнаруживается стандартный VNC TCP/5900, не все способы доступа |

**Утилита не обходит защиту компьютера.** Не используйте её вместо штатных мер безопасности, особенно на общем или рабочем Mac.

## Ограничения

- Определение именно физического ввода через Quartz HID — не гарантия: некоторые программные устройства выглядят для системы как физические.
- Подключение Screen Sharing проверяется по TCP/5900, другие протоколы могут не распознаваться.
- Это не режим экономии энергии и не настоящее отключение подсветки мониторов.
- Утилита использует права, выданные BetterDisplay и Hammerspoon; оцените их самостоятельно.
- Работа программного затемнения v2.3 проверялась на одном комплекте ASUS VG2791R + Acer XZ342CU V3 с Mac mini. Полноценные испытания на других моделях Mac и мониторах не проводились.

## Состав проекта

`physical_idle_query.c` — считывание HID idle; `betterdisplay_idle_dim.lua` — логика Hammerspoon; `install.sh` — установка; `disable.sh` и `enable.sh` — отключение и включение; `restore-brightness.sh` — восстановление; `uninstall.sh` — удаление.
